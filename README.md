# Project Anima · 产品经理笔试题

> 这是一道开放式系统设计 + vibe coding 题。你是「Project Anima」的属性架构师——给 SYB 的每个成员画一张「角色卡」。

## 这道题

请用 **RPG 角色卡 / 属性系统**的设计思维，为 SYB 设计一套「成员的能力与状态」系统——并亲手用 AI 做出一个可交互原型。

完整的题目要求、必答的五个问题、交付物格式，见 [`tasks/pm-attribute-system/README.md`](./tasks/pm-attribute-system/README.md)。
